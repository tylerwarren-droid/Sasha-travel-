### Component responsibilities

**`SashaAvatar.tsx`** — owns the HeyGen LiveAvatar session lifecycle.
- Creates `LiveAvatarSession(token, { voiceChat: false, video_settings: { quality: 'medium', encoding: 'H264' }})`.
- `voiceChat: false` — **we own the entire mic pipeline**; HeyGen does not touch the mic.
- Fetches token from `tokenUrl` (default `/api/heygen/token`).
- On `SESSION_STREAM_READY`: attaches video, sets keepAlive interval (every **150000ms / 150s**), registers speak handlers **exactly once** (guarded by `speakHandlersRegistered` — this was BUG 3).
- `speakFn(text)`: sets gate ON, calls `avatar.repeat(text)`, arms safety timer = `Math.max(1500, text.length*65)+900` ms which force-fires `openGate()` if `AVATAR_SPEAK_ENDED` never arrives.
- `interruptFn()`: calls `avatar.interrupt()`, clears timers, opens gate.
- `openGate()`: fires `onGate(false)`, `onAvatarSpeakingChange(false)`, `onSashaFinished()`, and **once only** (`hasOpenedMicRef`) `onReadyToListen()`.
- Maintains a 15s rolling speech buffer (`avatarSpeechBufferRef`) exposed via `onAvatarSpeechBuffer` for echo detection.
- Reconnect logic: on `SESSION_DISCONNECTED` reconnects after 2s **unless** reason is `MAX_DURATION_REACHED` (shows "tap to start new conversation"). On `SESSION_START_FAILED` retries after 3s. Reconnect guarded by `isReconnecting` + `isMountedRef`.
- Logs every `AgentEventsEnum` event to console (`[LA event]`).

**`VoiceButton.tsx`** — owns the mic → Deepgram STT pipeline.
- AudioWorklet PCM capture via `/pcm-capture.js`.
- `micGatedRef = useRef(true)` — **starts gated**; worklet runs immediately but audio is suppressed until first `AVATAR_SPEAK_ENDED`. Gate is a pure ref flag — no audio pipeline pause/resume.
- While gated: measures RMS; `> 0.0005` triggers `onInterrupt()` and opens gate immediately (`onInterruptRef` keeps the latest callback to avoid stale closure).
- While ungated: float32 → int16 → `ws.send(int16.buffer)`.
- Gate exposed to parent via `onSetGate` on mount (empty deps — stable). On gate-open it clears transcript, sets `isSpeaking(false)`, and sends `{ type: 'Finalize' }` to Deepgram to flush buffered avatar speech.
- Deepgram KeepAlive every **8s** (always on, not gated).
- Echo filter (`isEcho`): normalizes words, computes overlap vs `avatarSpeechGetter()`; `>= 0.7` overlap → discard.
- Dedup: identical `final` within 5s discarded (`lastFinal`/`lastFinalAt`, scoped per connection — this was BUG 4).
- **No auto-reconnect on `ws.onclose`** (intentional — see Gotchas).
- StrictMode guard in `ws.onopen`: if `wsRef.current !== ws`, discards the superseded socket.
- `autoStart && readyToListen && !disabled` → `connect()`.

**`vietnam/page.tsx`** — orchestration container.
- Gates everything behind a **tap-to-start overlay** (`started` state) — required for browser autoplay/mic gesture.
- `handleSetGate`/`handleGate` are `useCallback` with empty deps (**stable refs — mandatory, see Gotchas #3**).
- `voiceReady` set by `onReadyToListen`; drives `readyToListen` down to VoiceButton so **Deepgram does not connect until the avatar finishes its first greeting**.
- `isRespondingRef` lock — acquired in `handleSashaResponse`, released in `handleSashaFinished`; blocks transcript re-entry while Sasha is speaking.
- `lastRepeatTextRef` holds last spoken text, passed as `avatarSpeechGetter` for echo detection.
- Fetches initial background photos from Railway `/api/photos/search`; conductor updates photos per-turn via `onPhotos`.
- UI: 42% left column (avatar shrinks from 60% height → 160px when `engaged`; photo carousel), right column tabs (Sasha chat / Itinerary / Prefs / Trips). Runs as hardcoded `DEMO_USER` ("Alex").

### Known bug: echo / premature mic open

**Symptom:** mic gate occasionally opens during avatar speech → Deepgram transcribes the avatar's own voice → triggers a premature/spurious Sasha response.

**Mitigations currently in code (6 layers):**
1. `micGatedRef` — PCM frames dropped while avatar speaking.
2. 900ms trailing timer on `AVATAR_SPEAK_ENDED` (accounts for TTS tail).
3. Per-`repeat()` safety timer `max(1500, len*65)+900` ms (catches missing `AVATAR_SPEAK_ENDED`).
4. Deepgram `Finalize` sent on gate-open (flushes buffered speech).
5. Echo filter — 70% word-overlap vs last spoken text.
6. `isRespondingRef` lock — blocks re-entry while conductor responds.
