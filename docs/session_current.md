## 2. Voice Pipeline — Current State (WORKING, with known echo edge case)

### Data flow
```
HeyGen LiveAvatar (voiceChat: false — WE own the mic pipeline)
  → AVATAR_SPEAK_STARTED  → gate mic ON   (VoiceButton drops/suppresses PCM frames)
  → AVATAR_SPEAK_ENDED    → 900ms trailing timer → openGate() → gate mic OFF
                          → first time only: onReadyToListen() → starts Deepgram

Deepgram (nova-3, streaming WebSocket)
  ← AudioWorklet (pcm-capture.js) → linear16 PCM @ AudioContext native sample rate
  → interim + final transcripts → onTranscript() → conductor → Sasha response
  → response text → avatar.repeat(text) → HeyGen speaks it
```

### Exact component responsibilities

**`SashaAvatar.tsx`** — owns the HeyGen LiveAvatar session lifecycle and the speak-gate.
- Initializes `LiveAvatarSession(token, { voiceChat: false, video_settings: { quality: 'medium', encoding: 'H264' } })`.
- Fetches token from `tokenUrl` (default `/api/heygen/token`).
- **Gate ON:** `speakFn(text)` calls `onGate?.(true)` + `onAvatarSpeakingChange?.(true)`, then `avatar.repeat(text)`, then sets a **safety timer** = `Math.max(1500, text.length * 65) + 900` ms.
- **`AVATAR_SPEAK_ENDED`:** clears safety timer, starts a **900ms trailing timer** → `openGate()`.
- **`openGate()`:** `onGate?.(false)` + `onAvatarSpeakingChange?.(false)` + `onSashaFinished?.()`; the **first time only** (guarded by `hasOpenedMicRef`) calls `onReadyToListen?.()` which starts Deepgram.
- **Speak handlers registered exactly once** per avatar instance via `speakHandlersRegistered` flag (this was BUG 3 — duplicate registration).
- Maintains an **avatar speech buffer** (`avatarSpeechBufferRef`): captures `AVATAR_TRANSCRIPTION_CHUNK` / `AVATAR_TRANSCRIPTION` text with timestamps; exposed via `onAvatarSpeechBuffer` getter (filters to last 15s). Used for echo filtering.
- `interruptFn()` → `avatar.interrupt()` + clears timers + opens gate.
- `keepAlive()` every **150s**.
- Reconnect logic: on `SESSION_DISCONNECTED` reconnects after 2s **unless** reason is `MAX_DURATION_REACHED` (then shows "tap to start new conversation" error). On `SESSION_START_FAILED`, retries after 3s. Reconnect guarded by `isReconnecting` + `isMountedRef`.
- On `SESSION_CONNECTION_QUALITY_CHANGED === 'BAD'` → drops video to `quality: 'low'` and shows "Weak connection" badge.
- Re-inits on `visibilitychange` → visible when status is `idle`.

**`VoiceButton.tsx`** — owns the mic → Deepgram STT pipeline.
- Gets `getUserMedia` with echoCancellation/noiseSuppression/autoGainControl, creates `AudioContext`, `resume()`s immediately (Safari requires in-gesture).
- Opens Deepgram WS: `nova-3`, `en-US`, `smart_format`, `interim_results`, `endpointing=300`, `utterance_end_ms=1000`, `vad_events=true`, `encoding=linear16`, `sample_rate=<ctx.sampleRate>`.
- Loads worklet `/pcm-capture.js`, wires `MediaStreamSource → AudioWorkletNode → destination`.
- **`micGatedRef = useRef(true)`** — starts gated. Gate is a **pure ref flag** (audio pipeline keeps running; frames are just dropped).
- **While gated:** computes RMS of each frame. If `rms > 0.0005` → treat as user interrupt → fire `onInterruptRef.current?.()` and open gate immediately (`micGatedRef.current = false`). Otherwise `return` (drop frame as speaker bleed).
- **While ungated:** float32 → int16 PCM → `ws.send(int16.buffer)`.
- **Gate setter** exposed to parent on mount via `onSetGate` (empty deps — stable). On gate-OFF: clears transcript, sets not-speaking, sends `{ type: 'Finalize' }` to Deepgram to flush buffered avatar speech.
- **Transcript assembly:** accumulates `is_final` fragments into `transcriptRef`; fires only when `speech_final === true` and length ≥ 3. `UtteranceEnd` is a fallback if `speech_final` never arrives.
- **Dedup (BUG 4):** drops a final if identical to `lastFinal` within 5000ms.
- **Echo filter:** `isEcho()` normalizes words and checks ≥70% overlap against `avatarSpeechGetter?.()` — discards echoes.
- **KeepAlive** to Deepgram every 8s (always on, not gated).
- StrictMode guard in `ws.onopen`: if `wsRef.current !== ws`, the WS was superseded by cleanup — discard.
- **No auto-reconnect** on close (intentional — see gotchas).

**`vietnam/page.tsx`** — orchestration / state owner.
- `started` state gated by a **tap-to-start overlay** (audio init requires a user gesture).
- Renders `SashaAvatar` only when `started`. Wires:
  - `onGate={handleGate}` → `gateRef.current?.(value)` (stable via `useCallback`).
  - `onReadyToListen={() => setVoiceReady(true)}`.
  - `onSashaFinished={handleSashaFinished}` → releases `isRespondingRef` lock.
  - `onAvatarSpeakingChange={setIsAvatarSpeaking}`.
- `handleSetGate` (stable, empty deps) stores the gate setter from VoiceButton into `gateRef`.
- `handleSashaResponse(text)` → sets `lastRepeatTextRef`, acquires `isRespondingRef` lock, calls `speakFnRef.current?.(text)`, sets `engaged = true`.
- `voiceReady` drives `readyToListen` → SashaChat → VoiceButton (Deepgram doesn't connect until avatar finishes first greeting).
- Initial background photos fetched from `https://sasha-travel-production.up.railway.app/api/photos/search`; per-turn photos arrive via `onPhotos`.
- `avatarSpeechGetter={() => lastRepeatTextRef.current}` is what the echo filter checks against.

**`SashaChat.tsx`** — **not included in this handoff dump.** It threads VoiceButton, calls the conductor backend, and passes `onSashaResponse`, `onPhotos`, `onSetGate`, `onInterrupt`, `readyToListen`, `isRespondingRef`. **Read this file before editing the voice loop.**
