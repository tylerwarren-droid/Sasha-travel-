## 1. Voice Pipeline — Current State & Exact Component Responsibilities

The pipeline is **working** with known echo mitigations in place (see §2). Architecture flows: `vietnam/page.tsx` → `SashaAvatar` + `SashaChat` → `VoiceButton`.

### Data flow

```
HeyGen LiveAvatar (voiceChat: false — WE own the entire mic pipeline)
  → AVATAR_SPEAK_STARTED → gate mic ON  (VoiceButton drops PCM frames)
  → AVATAR_SPEAK_ENDED   → 900ms trailing timer → gate mic OFF
                         → first time only: onReadyToListen() → starts Deepgram

Deepgram (nova-3, streaming WebSocket)
  ← AudioWorklet (pcm-capture.js) → linear16 PCM @ AudioContext native sample rate
  → interim + final transcripts → conductor → Sasha response text
  → response text → avatar.repeat(text) → HeyGen speaks it
```

### Component responsibilities

#### `frontend/app/components/SashaAvatar.tsx` — HeyGen session lifecycle
- Fetches token from `tokenUrl` (default `/api/heygen/token`), dynamically imports `@heygen/liveavatar-web-sdk`.
- Constructs `LiveAvatarSession(token, { voiceChat: false, video_settings: { quality: 'medium', encoding: 'H264' } })`.
- **`speakFn(text)`** exposed to parent via `onAvatarReady`:
  - clears timers → `onGate?.(true)` → `onAvatarSpeakingChange?.(true)` → `avatar.repeat(text)` (⚠️ **single argument only**).
  - Sets **safety timer** = `Math.max(1500, text.length * 65) + 900` ms → fires `openGate()` if `AVATAR_SPEAK_ENDED` never arrives.
- **`interruptFn()`** → `avatar.interrupt?.()` + clears timers + opens gate + `onSashaFinished?.()`.
- **Event handlers** (registered exactly once per instance via `speakHandlersRegistered` guard — this is **BUG 3** mitigation):
  - `AVATAR_SPEAK_STARTED` → logs only.
  - `AVATAR_SPEAK_ENDED` → clears safety timer, starts **900ms trailing timer** → `openGate()`.
  - `SESSION_STOPPED` → clears timers, opens gate, `onSashaFinished()`.
  - `AVATAR_TRANSCRIPTION_CHUNK` / `AVATAR_TRANSCRIPTION` → push to `avatarSpeechBufferRef` (used for echo filtering; 15s rolling window exposed via `onAvatarSpeechBuffer`).
- **`openGate()`** → `onGate?.(false)` + `onAvatarSpeakingChange?.(false)` + `onSashaFinished?.()`; on first call only sets `hasOpenedMicRef` and fires `onReadyToListen?.()` (**this is what starts Deepgram**).
- **`keepAlive()`** called every **150s** (⚠️ method name is `keepAlive`, not `ping`).
- **Reconnect logic:** on `SESSION_DISCONNECTED` → reconnect after 2s **unless** reason is `MAX_DURATION_REACHED` (shows "Session ended — tap to start"). On `SESSION_START_FAILED` → reconnect after 3s.
- Connection-quality handler downgrades to `quality: 'low'` on `BAD`.
- Re-inits on `visibilitychange` → `visible` if status is `idle`.

#### `frontend/app/components/VoiceButton.tsx` — mic capture + Deepgram STT
- Uses `getUserMedia` with `echoCancellation/noiseSuppression/autoGainControl: true`.
- Creates `AudioContext`, `resume()`s immediately (Safari gesture requirement), loads `/pcm-capture.js` AudioWorklet.
- **WebSocket** to Deepgram: `nova-3`, `en-US`, `smart_format`, `interim_results`, `endpointing=300`, `utterance_end_ms=1000`, `vad_events=true`, at **AudioContext native sample rate**.
- **Gate** = `micGatedRef = useRef(true)` — starts **gated**. Pure ref flag (no pipeline pause). Registered to parent via `onSetGate` on mount (empty deps).
  - While **gated**: measures RMS per frame; if `rms > 0.0005` → treat as user interrupt → `onInterruptRef.current?.()` + open gate immediately; else drop frame (speaker bleed).
  - On **gate-open**: clears `transcriptRef`, sends `{ type: 'Finalize' }` to Deepgram to flush buffered avatar speech.
- While **ungated**: float32 → int16 PCM → `ws.send(int16.buffer)`.
- **Transcript handling:** accumulates `is_final` fragments in `transcriptRef`; fires on `speech_final === true` (≥3 chars) OR `UtteranceEnd` fallback.
- **Dedup (BUG 4):** drops a final identical to `lastFinal` within 5s.
- **Echo filter:** `isEcho()` — discards transcript if ≥70% word overlap with `avatarSpeechGetter()`.
- **KeepAlive** to Deepgram every **8s**. **No auto-reconnect on close** (intentional — see gotchas).
- **StrictMode guard:** `ws.onopen` checks `wsRef.current !== ws` and discards superseded sockets.

### Known bug — echo / premature transcription
**Issue:** Mic gate occasionally opens during avatar speech, letting Deepgram transcribe the avatar's voice → premature/spurious response.

**Mitigations currently in place (all live):**
1. `micGatedRef` — drops PCM frames while avatar speaking.
2. 900ms trailing timer on `AVATAR_SPEAK_ENDED` (TTS tail).
3. Per-`repeat()` safety timer (catches missing `AVATAR_SPEAK_ENDED`).
4. Deepgram `Finalize` on gate-open (flush buffered speech).
5. Echo filter — 70% word-overlap vs. last spoken text.
6. `isRespondingRef` lock — blocks re-entry while conductor responds.

**Status:** HeyGen support reviewed source (the reason the repo is public). `AVATAR_SPEAK_STARTED`/`ENDED` confirmed firing; gate confirmed working in console (`[GATE] set to true/false`). **Awaiting HeyGen diagnosis** — likely event-timing or a `voiceChat: false` edge case.
